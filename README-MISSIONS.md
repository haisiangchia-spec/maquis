# Mission-placement and PDF art update

Two clickable mission-card spaces sit above the board, aligned with the top exits above Fence (left) and Pont du Nord (right). Their road connections in `EDGES` are `missionA–fence` and `missionB–north`. Players can place workers on them and perform the original **prototype** missions Supply Run and Radio Network. The cards have per-slot art selectors containing six mission card crops from the user-supplied January 2014 print-and-play PDF; selecting imagery does **not** change mission requirements.

The supplied 2014 PDF states that mission cards contain worker-placement task rectangles, one task action per turn. The task rules for the six published missions are **not implemented** in this milestone. The 2021 published edition may differ. The rest of the prototype rules remain simplified.

Before public distribution of printed artwork, confirm the relevant artwork redistribution rights. Assets are stored under `public/missions`.

For GitHub Pages: copy/re-upload all files keeping folders intact and push `main`. GitHub Actions deploys `dist`.
